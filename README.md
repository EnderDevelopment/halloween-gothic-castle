# Halloween Gothic Castle

Halloween Gothic Castle is a Minecraft Bedrock plugin that generates a complete 360-degree Gothic castle with a central keep, asymmetrical towers, crimson pointed roofs, detailed backside, bridges, balconies, battlements, interior rooms, and accessible corridors. The castle is built using vanilla blocks only and features a custom mountain, winding stone path, red ground, and rocky blocks. Decorations include twisted dead trees, soul lanterns, chains, cobwebs, pumpkins, mob heads, armor stands, and a hidden composter scare. The interior includes a grand hall, bedrooms, library, enchanting room, storage, furnished tower rooms, and a Halloween room.

## Install

1. Download the Halloween Gothic Castle addon file (.mcaddon).
2. Open Minecraft Bedrock Edition.
3. Go to the "Add-Ons" section in the settings.
4. Click on "Add" and select the downloaded .mcaddon file.
5. Enable the Halloween Gothic Castle addon.

## Use

1. Open a Minecraft Bedrock Edition world.
2. Use the command `/function halloween_castle` to generate the Halloween Gothic Castle.
